# Open Ground community

Community resources for Open Ground, a squad tactics wargame.

- [`relays/`](relays/): **community co-op relays**. Run a relay ([open-ground-relay](https://github.com/javimosch/open-ground-relay))
  and add it here: every game then lists it as a community relay.
- [`modkit/`](modkit/): **make your own mods and expansions**: a how-to, the format references, an example mod and an example expansion. Validators for Windows and Linux are on the [Releases](../../releases) page.

Pull requests and issues welcome.
